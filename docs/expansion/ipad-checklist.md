# เช็กลิสต์ทดสอบบน iPad

ทดสอบบนเว็บจริงหลัง push (https) เพราะ Web Share ใช้ได้เฉพาะ https

## รอบ 1 — เซฟสำรอง ส่งออก นำเข้า

ทำตามลำดับ ใช้เซฟทดสอบได้ แต่ถ้าใช้เซฟจริงให้ทำข้อ 2 ก่อนข้อ 3

### เตรียม
- [ ] 1. เปิดเกม เล่นให้มีความคืบหน้าเล็กน้อย เช่น ตอบคำ 5–10 คำ แล้วจดจำนวน "คำที่จำได้" หรือคะแนนไว้
- [ ] 2. ไป ตั้งค่า > ข้อมูล ดูว่าแถว "เก็บไว้ที่" ขึ้น "เครื่องนี้" และมีบรรทัดบอกสถานะการปกป้องข้อมูล

### ส่งออกไปแอปไฟล์
- [ ] 3. กด "ส่งออกเซฟ" ควรขึ้นหน้าต่างแชร์ของ iPad
- [ ] 4. เลือก "บันทึกไปยังไฟล์" แล้วบันทึก ชื่อไฟล์ต้องขึ้นต้น `vocab-zombie-save-` และลงท้าย `.vzsave`
- [ ] 5. เปิดแอปไฟล์ ดูว่ามีไฟล์จริง
- [ ] 6. กลับเข้าเกม แถว "ไฟล์สำรองล่าสุด" ต้องขึ้น "วันนี้"
- [ ] ถ้าไม่ขึ้นหน้าต่างแชร์ แต่เบราว์เซอร์ดาวน์โหลดไฟล์แทน ให้จดไว้ แล้วดูไฟล์ในโฟลเดอร์ดาวน์โหลด

### ลบข้อมูลเว็บแล้วนำเข้ากลับ
- [ ] 7. ปิดเกม ไปแอปตั้งค่า > Safari > ขั้นสูง > ข้อมูลเว็บไซต์ แล้วลบเฉพาะของเว็บเกม
- [ ] 8. เปิดเกมใหม่ ต้องเป็นผู้เล่นใหม่ (ความคืบหน้าหายไป)
- [ ] 9. ไป ตั้งค่า > ข้อมูล กด "นำเข้าเซฟ" แล้วเลือกไฟล์จากข้อ 4 ไฟล์ต้องเลือกได้ ไม่เป็นสีเทา
- [ ] 10. ต้องขึ้นตารางเทียบ "เครื่องนี้" กับ "ไฟล์" มีวันที่ คำที่จำได้ ด่าน และเวลาเล่น
- [ ] 11. กด "แทนที่" แล้วกด "เริ่มใหม่"
- [ ] 12. ความคืบหน้าต้องกลับมาเหมือนข้อ 1 รวมการตั้งค่าและตำแหน่งปุ่ม touch

### รวมเซฟและข้อมูลสำรอง
- [ ] 13. เล่นเพิ่มอีกนิด แล้วนำเข้าไฟล์เดิมแบบ "รวม" ความคืบหน้าใหม่ต้องไม่หาย
- [ ] 14. ไป ตั้งค่า > ข้อมูล ส่วน "ข้อมูลสำรองอัตโนมัติ" ต้องมีรายการ "ก่อนรวมเซฟ" กด "กู้คืน" แล้วยืนยัน
- [ ] 15. นำไฟล์ `.json` เซฟรุ่นเก่า ถ้ามี มานำเข้า ต้องอ่านได้

### ปิดแอปกะทันหัน
- [ ] 16. ระหว่างเล่นในด่าน ตอบคำให้ถูกสักคำ แล้วปัดปิดแอปหรือปิดแท็บทันที
- [ ] 17. เปิดเกมใหม่ คำนั้นต้องยังถูกนับ

### ติดตั้งบนหน้าจอโฮม
- [ ] 18. เพิ่มเกมลงหน้าจอโฮม แล้วเปิดจากไอคอน ทำข้อ 3–4 ซ้ำอีกครั้ง

### รีเซ็ต
- [ ] 19. ทำเฉพาะกับเซฟทดสอบ: กด "รีเซ็ต..." ต้องพิมพ์รหัส 4 หลักที่แสดงก่อน ปุ่มรีเซ็ตจึงกดได้
- [ ] 20. หลังรีเซ็ต การตั้งค่ายังอยู่ และมีรายการ "ก่อนรีเซ็ต" ให้กู้คืนได้

### คำเตือนในเมนูหลัก
ข้อนี้ต้องรอให้ไม่ได้ส่งออกเกิน 7 วัน จึงตรวจทีหลังได้
- [ ] 21. ถ้ามีความคืบหน้าใหม่และไม่ได้ส่งออกเกิน 7 วัน เมนูหลักต้องมีการ์ด "สำรองความก้าวหน้าของคุณ" และปิดได้
