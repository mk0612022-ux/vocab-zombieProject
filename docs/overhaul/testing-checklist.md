# Testing Checklist — การปรับเปลี่ยนครั้งใหญ่ (รอบ 8)

ส่วนที่ 1 คือผลทดสอบอัตโนมัติ (รันบนเครื่องพัฒนา, headless Edge) · ส่วนที่ 2 คือเช็กลิสต์ให้ผู้ใช้ทดสอบเองบน iPad และ PC (สิ่งที่เครื่องตรวจแทนไม่ได้: ความรู้สึกมือ หู ตา และความลื่นบนเครื่องจริง)

## วิธีรันชุดทดสอบอัตโนมัติ

1. `powershell -File serve-lan.ps1` (เปิด http://localhost:8080 พร้อม `/tools/`)
2. เปิดเกมในเบราว์เซอร์ รอเมนูหลัก แล้วใน console:
   ```js
   const s = document.createElement("script"); s.src = "/tools/round28-test.js"; document.head.append(s);
   // เมื่อโหลดแล้ว
   const r = await G.Round28Test.run(); r.fail   // [] = ผ่านทั้งหมด
   ```
   เปลี่ยนเลขเป็น 1–29 ได้ (ชุด 21–28 = งานนี้ รอบ 1–8, ชุด 29 = ปืนตามคลิปอ้างอิง) · เสียงปืนเทียบหัวข้อ 5: โหลด `/tools/gun-sound-check.js` แล้ว `await G.GunSoundCheck.runAll()`
3. stress test: โหลด `/tools/stress-test.js` แล้ว `await G.StressTest.run(["medium"], 600)`
4. ตรวจข้อความล้น/ทับ: โหลด `/tools/ui-text-audit.js` แล้วทำตามหัวไฟล์
5. ไฟล์และข้อความ: `tools/check-strings.ps1`, `tools/thai-scan.ps1`, `tools/check-paths.ps1`, `tools/validate-words.ps1`

## ส่วนที่ 2 — เช็กลิสต์ทดสอบเอง (iPad เป็นหลัก)

เตรียม: iPad ต่อ Wi-Fi เดียวกับ PC ที่รัน `serve-lan.ps1` (หรือหลัง push ใช้เว็บจริง) · Settings > Graphics ใช้ **Medium** (ค่าที่ออกแบบไว้สำหรับ iPad) · เปิดเสียง ใส่หูฟังได้ยิ่งดี
ลิงก์ช่วยทดสอบ: `?lab=weapons` (ปืนทุกกระบอกทุกสถานะ), `?lab=sound` (ฟังเสียงทุก event + มิเตอร์), `?lab=zombies` (ซอมบี้ 10 ชนิด + ท่า), `?debug=1` (สถานะปืน, เฟรม, งบเอฟเฟกต์, จำนวนเสียง, ปุ่ม Stress)

### Animation

- [ ] รีโหลดแล้วสลับปืนกลางคัน แล้วกลับมา: กระสุนถูกต้อง (ใส่ไม่ครบถ้ายังไม่ถึงจังหวะใส่แม็ก)
- [ ] มือไม่ทะลุปืน ปืนไม่ลอยหลุดจากกล้องเวลามองขึ้นลงสุด / กระโดด / ตกลงพื้น
- [ ] inspect (PC: G · iPad: กดปุ่มรีโหลดตอนแม็กเต็ม · จอยเกม: X ตอนแม็กเต็ม) แล้วยิงทันที: ท่ายกเลิกได้ ไม่ค้าง
- [ ] ซอมบี้แต่ละชนิดเปลี่ยนท่า (เดิน → วิ่ง → โจมตี → โดนยิง → ตาย) นุ่ม ไม่วาร์ป
- [ ] `?lab=weapons` ดูทุกกระบอกบน iPad อย่างน้อยกระบอกละครั้ง

### Audio

- [ ] ยกเลิกรีโหลดกลางคัน: เสียงรีโหลดหยุด ไม่ค้าง
- [ ] ในทางเดิน / ห้อง / สนาม / ใต้ดิน เสียงก้องต่างกันพอรู้สึก ไม่ก้องจนเลอะ
- [ ] ยิงหนัก ๆ กับซอมบี้เยอะ: ยังได้ยินเสียงเตือน (บอส, Screamer, คำถาม) ไม่แตก ไม่ดังจนแสบหู

- [ ] Settings > Audio: ทุกแถบเสียง (Master, Music, Weapons, SFX, Ambient, UI, Speech) ปรับแล้วได้ผลจริง

### ปืนตามคลิปอ้างอิง (`docs/reference/guns/GUN_REFERENCE.md`)
ปืนตัวแทนของแต่ละต้นแบบ (ดูใน `?lab=weapons` หรือเก็บในด่าน): LMG `last_stand` · ไรเฟิลไม้ `void_principal` · SMG `scrap_spitter` · ปืนพก `pistol` · .45 `nut_cracker` · .50 `overwatch` · สไนเปอร์ peep `sniper` · สไนเปอร์ขาว `vital_sign` · สไนเปอร์เลนส์น้ำเงิน `honor_roll`
- [ ] ท่า hip เห็นปืนชัด (ไม่จมใต้แขน) ปืนพกอยู่กลางล่าง · เล็งแล้วศูนย์อยู่กลางจอพอดี (LMG วงแหวนเขียวในบล็อกศูนย์, SMG แท่ง tritium, ปืนพกตัว U, .50 กรอบ + บั้ง cyan, สไนเปอร์ peep แปดเหลี่ยม + เสาเขียว)
- [ ] กล้องเล็งของสไนเปอร์ขาวมีจุดแดงกลาง ของเลนส์น้ำเงินไม่มี
- [ ] สไนเปอร์ peep: ยิงแล้วลดปืนลงมาขึ้นลำ (ปลอกกระเด็นตอนดึง bolt) แล้วกลับมาเล็งเอง · .50: ยิงแล้วยังเล็งอยู่ ปืนจมลงแล้วกลับ · ลูกไฟ .50 ใหญ่มีขอบควันน้ำตาล
- [ ] สีอ่านออกในฉากกลางคืน (ไม้ของไรเฟิล, ขาวของสไนเปอร์ขาว, เงินของ .50)
- [ ] เสียง: LMG ยิงรัวแล้วหางคำรามค้าง · ไรเฟิล "แคร็ก" + sub หนัก ได้ยินจังหวะทีละนัด · SMG สว่าง "บรืด" · .50 ดังสุด หางยาว · ความดัง .50 > LMG > ไรเฟิล > .45 > 9 มม. > SMG · หยิบปืน/ขึ้นลำ/รีโหลดเบากว่าเสียงยิงชัดเจน · ปลอกตกพื้นมีเสียงตามพื้น
