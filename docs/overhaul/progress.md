- `js/captions.js` (ใหม่): คำบรรยายเสียงสำคัญพร้อมลูกศรทิศ (4 ภาษา) · `js/data/soundbank.js` (ใหม่): event 55 รายการ → recipe, พร้อมรับไฟล์ CC0 + credits

  - ฉากเล็ก (< 1 MB + shadow 4 MB; target ของ pass หลังฉากปล่อยทิ้งระหว่างเล่นด่าน)

  - หน้า Inventory Full มีแถวช่องแบบเดียวกับ HUD: ชี้/โฟกัสการ์ดไหน ช่องที่จะถูกแทนจะสว่างแดงในแถว และกดช่องในแถวเพื่อเลือกได้
- กระสุน: ตัวเลขความกว้างเท่ากัน, ≤ 25% อำพัน, หมดแม็ก = แดง + RELOAD นิ่ง ๆ (สำรองหมดด้วย = NO AMMO), แถบรีโหลดบาง ๆ จาก timer ของ gameplay
- แถบเลือด: % ปัดขึ้น (0% เฉพาะตอนตาย), ลดแบบ smooth + damage chip สีอ่อนตามหลัง, ต่ำกว่า 30% pulse ช้า (1.8 วิ), regen เรืองเขียวจาง ๆ; stamina หมดแรง = เทาจนฟื้น
- สไตล์ตามสเปก: พื้น `rgba(18,20,23,0.62)` เส้นขาวบาง 1 px `rgba(255,255,255,0.85)` แดง `#E5484D` น้ำเงิน `#3B82F6` เขียว `#4ADE80` เหลือง `#FACC15` ฟ้า `#5ED6FF`
- จัดวางอัตโนมัติ (`G.Hud.fit`):
  - จอกว้าง: ทุกอย่างในแถวเดียว แผงขวาอยู่ข้างแถวช่อง
  - จอแคบ/touch: แผงขวาย้ายไปซ้อนเหนือปลายขวาของแถวช่อง (แผงย่อเหลือ 2–3 บรรทัด)
  - touch: HUD อยู่ระหว่างปุ่มสองฝั่ง (คำนวณจากตำแหน่งปุ่มจริง) ไม่ทับ joystick ปุ่มยิง ปุ่มเล็ง
  - ไม่มีที่ระหว่างนิ้ว (มือถือแนวตั้ง): ยก HUD ขึ้นเหนือปุ่ม กว้างเต็มจอ
  - รองรับค่าปรับขนาด HUD เดิม (เพิ่มส่วน "ช่องอาวุธ") และ safe area
  - ข้อความโต้ตอบ (Press E), คำบรรยายเสียง, แถบสะกดคำ, ปุ่ม ability บน touch และโน้ตต่าง ๆ อยู่เหนือ HUD เสมอ (ตัวแปร `--dock-h`/`--dock-b`)
- หน้าแก้ไขตำแหน่งปุ่ม touch: แสดงกรอบ HUD (เส้นประเหลือง + ป้าย) ลากปุ่มไปวางบน HUD → ปุ่มเด้งขึ้นไปอยู่เหนือ HUD
  - migration: layout ที่เซฟไว้ก่อนหน้าที่มีปุ่มทับตำแหน่ง HUD ใหม่ → ตอนโหลดเลื่อนปุ่มขึ้นและเซฟใหม่; ค่าตำแหน่งของ "แถวอาวุธ" เดิมถูกลบ

- Game Over / เริ่มใหม่ / เปลี่ยนด่าน / ต่อจาก checkpoint → `G.Hud.reset()` ล้างค่าทั้งหมดแล้วอ่านจาก state ใหม่

**ตัวเลข** (headless Edge)
- ความสูงของ HUD ที่ขนาดค่าเริ่มต้น (สเปก: ไม่เกินประมาณ 18%):

## รอบ 8 — ทดสอบรวม ประสิทธิภาพ และเตรียม deploy
**ทำแล้ว**
- ตาราง Quality Tier: ตรวจครบทุกช่องกับสเปก (particle, decal, แสง muzzle, reverb, HRTF, occlusion, จำนวนเสียง, variant เสียงปืน, ลำแสง/หมอก, DoF เมนู)
  - เมนูหลัก Medium = "แบบง่าย" ตามสเปก: 2 ลำแสง + หมอก 1 ชั้น (เดิม Medium ได้ครบ 5 ลำแสง 2 ชั้น); ค่าอยู่ใน `G.CONFIG.menuScene` (shafts / fog / dust ต่อ tier)
  - แก้: งบรอยกระสุน (decal) เดิมนับแยกต่อชนิดรอย 4 ชนิด จึงมีได้ถึง 4 เท่าของตาราง (Low 96 แทน 24) → นับรวมทุกชนิด เกินงบแล้วลบรอยที่เก่าที่สุดก่อน (`js/fx.js`)
- Accessibility (Settings > Accessibility):
  - ใหม่: **Weapon Bob** (ปืนในมือโยกตอนเดิน/วิ่ง 0–100%), **Screen effects** (ขอบแดงตอนโดนตี, เลือดน้อย, Focus Time, ฟ้าผ่าบอส, กล่องสุ่ม 0–100%), ปุ่ม **HUD size** (editor เดิม) อยู่ข้าง UI scale
  - **UI scale** (เดิม "Font size"): ตั้งขนาดตัวอักษรของทั้งหน้า 90% / 100% / 112% (CSS ใช้ rem ทั้งหมด) และเอากฎขยายเฉพาะบางจุดแบบเก่าออก (เดิมขยายซ้อนกัน)
  - **Reduce Motion** ทำมากขึ้น: นอกจากกล้องเมนูนิ่ง → camera shake ×0.35, head bob/weapon bob ×0.5, Screen effects ×0.6, หลอดไฟในด่านไม่กะพริบ/ไม่วูบ, ไฟสนามตอนบอสมาค่อย ๆ สว่างแทนกะพริบ, หลอดไฟในเมนูหลักนิ่ง
  - Camera Shake ใช้กับ cutscene บอสด้วย (เดิมไม่ขึ้นกับค่าตั้ง)
  - `G.Access` (`core.js`) รวมตัวคูณให้ทุกระบบอ่านที่เดียว + ตัวแปร CSS `--fx-screen`
  - มีอยู่แล้วจากรอบก่อน: Camera Recoil (0 = ปิด), Muzzle Flash, Blood & Gore, เสียง 7 แถบ, Captions
  - Motion Blur: เกมไม่มี motion blur จึงไม่มีแถวนี้
  - Save: migration — save เก่าได้ Weapon Bob / Screen effects 100%, ค่าผิดถูกบีบเข้าช่วง 0–1, ขนาด UI ที่ไม่รู้จักกลับเป็น 100%
- HUD บนจอแคบ (ค้างจากการตรวจรอบ 7, มือถือแนวตั้ง 399×904):
  - คอลัมน์ ability หลุดจอหลังรังผึ้ง: HUD จัด layout ตามสถานะ ability bar ตอนเกมหยุดอยู่ไม่ได้ → `G.Hud.syncAb()` เรียกจาก `fit()` และ ability bar สั่ง refit เมื่อเปลี่ยน
  - แถวช่องในหน้า Inventory Full (7 ช่อง) ล้นจอ → ขึ้นบรรทัดใหม่
  - บรรทัดภารกิจ/ชั้น 3 ที่ HUD 150% ถูกตัด "…" → ขึ้นบรรทัดใหม่บนจอแคบ
- หน้า How to Play: ส่วนใหม่ HUD (กลางล่าง, กล่องคำ, การ์ดคำอธิบาย), ปุ่ม inspect (G / จอสัมผัส: ปุ่มรีโหลดตอนแม็กเต็ม / จอย: X), ซอมบี้ 10 ชนิดพร้อมเวฟแรกและวิธีรับมือ, คำอธิบายคำตอบและค่าตั้ง; แก้ส่วนเดิมที่อ้าง Progress ในลอบบี้ → เมนูหลัก > Learn — 4 ภาษา
- เอกสาร: `integration.md`, `testing-checklist.md`, `performance-notes.md`
