## รอบ 2 — รูปลักษณ์อาวุธ + Muzzle Flash / Smoke / Impact
**ทำแล้ว**
- `js/gunskin.js`: ผิวปืน 5 แบบ (matte, worn, bare, polymer, rubber grip) เป็น pixel texture 16 px วาดตอนโหลด + roughness/metal ต่อผิว (รอยขีด ฝุ่น ขอบสึก) คูณกับสีเดิมของแต่ละชิ้น → **สีเอกลักษณ์ทุกกระบอกอยู่ครบ**, vertex AO ตรงรอยต่อชิ้นและใต้มือ, ปืนทั้งกระบอกรวมเป็น mesh เดียว (+ glow + ชิ้นที่ขยับ) — ปืนทั้ง 85 กระบอกและมีดใช้ตัวสร้างเดียวกันจึงอัปเกรดพร้อมกันทุกด่าน (โรงเรียน → โรงพยาบาล → บังเกอร์)
- แขนในมือ: รวมกล่องต่อกระดูกเป็น mesh เดียว (16 → 8)
- `js/fx.js`: muzzle flash sprite 4 แบบ ขนาดตามตระกูล 40–60 ms + แสงจาก pool เดิม (ทุกนัดบน Medium+, ทุก 2 นัดบน Low, ไม่มีบน Very Low, ปืนเร็วเกิน 600 RPM แสงครึ่งเดียว), ควัน (1 draw call, จางใกล้กลางจอ), ปลอกกระสุนจาก pool, เศษกระทบตามพื้นผิว + รอยกระสุน 4 แบบที่จางหาย, งบ particle/decal ตาม tier (ตารางในสเปก)
- `js/surface.js`: surfaceType กลาง 9 แบบ (พื้นตามชนิดห้อง, ผนัง, ประตูเลื่อน, ลัง, ถังขยะ, เสา) — รอบ 3 ใช้กับเสียงกระทบและฝีเท้าต่อ
- `game.js`: `shotImpact()` (จุดที่กระสุนตก — แค่ภาพ เส้นทางกระสุนเหมือนเดิม), ลูกซองมีรอยไม่เกิน 3 รูต่อนัด, ประตูเลื่อนไม่มีรอย
- ตั้งค่าใหม่: Muzzle Flash 0–100% (Accessibility, 4 ภาษา) · debug overlay แสดงจำนวน particle/รอยกระสุน/ปลอก เทียบงบ
- ทดสอบ: `tools/round22-test.js` (41 ข้อ) · ภาพปืนทุกตระกูล `docs/overhaul/screens/round2-guns.jpg`

## รอบ 3 — ระบบเสียงทั้งเกม
**ทำแล้ว** (รายละเอียดเต็ม: `audio-event-map.md` §7)
- `audio.js`: mixer ใหม่ Master → Compressor → Limiter → Ceiling (ไม่เกิน −1 dBFS) แยก bus music / weapons (มี EQ) / sfx / ambient / ui / reverb · pause ปิดเสียงเกมแต่ UI ยังดัง, music −6 dB · ducking (บอสเตือน, หน้าต่างคำถาม/ควิซ, cutscene: music −6 dB, ambient −4 dB) · ระบบ voice ต่อหมวด + เพดานรวมตาม tier + steal (สำคัญน้อย → ไกล → เก่า) · tag ต่อ reload/switch/inspect (cancel หยุดทันที) · `stopAll()` ตอนตาย/ชนะ/ออกด่าน · ฝีเท้า 7 พื้นผิว + เสียงลงพื้น · เสียงกระสุนกระทบ 9 พื้นผิว · ฝีเท้าซอมบี้ 3 ตัวใกล้สุด + horde bed · occlusion (ผนัง/ประตูปิด: lowpass + −6 dB) · HRTF เฉพาะ High/Ultra
- `gunaudio.js`: เสียงยิง pre-render ด้วย OfflineAudioContext (2–6 variant ตาม tier, ไม่ซ้ำติดกัน, pitch ±3%, ±1 dB) · ปรับความดังทุกกระบอกให้อยู่ใน ±1.5 dB ของค่ากลางตระกูล · ทุกเสียงปืนมาจาก G.Bus (`weapon:fire`, marker รีโหลด, switch, inspect) · เตือนกระสุนใกล้หมด (ครั้งเดียว), กระสุนสำรองหมด (เสียงปฏิเสธ + ข้อความ HUD)
- `js/acoustics.js` (ใหม่): 6 zone (Indoor Corridor, Underground Corridor, Small Room, Large Interior, Warehouse, Outdoor) IR procedural, convolver A/B crossfade 0.6 s · Very Low ไม่มี reverb, Low delay, Medium IR สั้น, High เต็ม, Ultra + far echo
- `js/captions.js` (ใหม่): คำบรรยายเสียงสำคัญพร้อมลูกศรทิศ (4 ภาษา) · `js/data/soundbank.js` (ใหม่): event 55 รายการ → recipe, พร้อมรับไฟล์ CC0 + credits
- ตั้งค่า (4 ภาษา): Master, Weapons, UI ใหม่ + ปุ่มทดสอบเสียงทุก fader + Captions · migration save เก่า (Weapons/UI = ค่า SFX เดิม)
- debug overlay: บรรทัดเสียง (voice ต่อหมวด/เพดาน, peak, zone) + ปุ่ม Stress · `js/lab/sound.js` (`?lab=sound`): มิเตอร์ peak, ยิง/รีโหลดทุกปืน, ทุก event จาก 5 ทิศ, บังคับ zone, วัดเสียงทุกกระบอก, captions

- Sprinter เริ่มเวฟ 3 (เดิมเวฟ 2), Crawler เริ่มเวฟ 4 (เดิมเวฟ 1) ตามตารางในสเปก — เวฟ 1 เป็น Shambler ล้วน ความเร็วเท่าเดิม
- Shambler ตาเปลี่ยนจากแดงเรืองเป็นครีมขุ่น (สีตาเป็นเอกลักษณ์ต่อชนิด)
- ซอมบี้ "ถือหัว" และ "แขนยาว" ที่เคยสุ่มบน Shambler กลายเป็นชนิด Headless / Reacher (Shambler เหลือหน้าเบี้ยวกับแขนบวม)
- ป้ายคำอยู่เหนือหัวจริงของแต่ละชนิด (เดิมสูงคงที่ ~2.3 m) และ Sprinter/Crawler ป้ายขนาดเท่าตัวอื่นแล้ว (เดิมเล็กตาม scale)

**ปัญหา / หมายเหตุ (มีมาก่อนรอบนี้)**
- ชุดทดสอบ 22 "ประตูระดับ Low ต่ำกว่า 150 draw calls" ผ่านบ้างตกบ้าง: โลกอย่างเดียววัดได้ 130–147 ทั้งรุ่นก่อนและหลังรอบนี้ (ของตกแต่งในโรงเรียนสุ่มทุกครั้งที่สร้างด่าน) + ปืนและแขน 8
- ชุดทดสอบ 16 "คำบนหน้า Loading ไม่ล้นจอ" ตกบ่อย: คำขวาสุดล้นขอบ 15–20 px มีมาก่อนรอบ 3 (แยกเป็นงานต่างหากแล้ว)
