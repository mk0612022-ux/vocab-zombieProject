## วิธีวัด (ตามหัวข้อ 5)

- เสียงที่วัด = เสียงยิงแบบที่เกมเล่นจริงกลางแจ้ง (สูตรใน `public/js/gunvoice.js` เรนเดอร์แบบ offline: เสียงแห้ง + หาง outdoor ไม่มี reverb ของห้อง) — **ทุกเสียงสร้างด้วยโค้ด ไม่มีเสียงจากวิดีโอ**
- แต่ละกระบอกวัด **6 นัด** = 6 variant ที่เกมเล่นจริง (pitch 1, 0.985, 1.015, 0.97, 1.03, 0.993 แต่ละนัด noise คนละชุด) แล้ว **ใช้ค่ามัธยฐาน** — แบบเดียวกับที่เอกสารรายงานค่ามัธยฐานของหลายนัดในหัวข้อ 3
- onset = ตัวอย่างแรกที่ดังถึง −20 dB จากจุดดังสุด · ช่วง transient 0–15 ms · body 15–120 ms · tail 120–600 ms
- centroid = ค่าเฉลี่ยความถี่ถ่วงพลังงานของ FFT (Hann) ช่วง 20 Hz–20 kHz · แถบความถี่ = % พลังงานในแถบ · sub = ยอดความถี่ต่ำกว่า 250 Hz ในช่วง body
- decay = RMS หน้าต่าง 20 ms ทุก 2 ms ผ่าน minimum filter 60 ms นับจาก onset (หรือจากนัดสุดท้ายของชุดยิง) ถึงจุดที่ลด 10 / 20 dB จากยอด
- ชุดยิง (LMG 2.8 วิ, SMG 1.0 วิ) วัดจากการยิงต่อเนื่องตามอัตรายิงของปืนกระบอกนั้น
- **ค่าคลาดเคลื่อนที่ยอมรับ**: centroid ±25% · แถบความถี่ ±10 จุด · decay ±30% · อัตรายิง ±5% (หัวข้อ 5) · sub ±10 Hz (เลือกจากช่วงที่หัวข้อ 6 ให้สุ่มได้)
- อัตรายิงตรวจเฉพาะ "ตัวแทน" (★) ของแต่ละต้นแบบ — กระบอกอื่นมีอัตรายิงของตัวเองตามสมดุลเกม (แสดงค่าไว้ในคอลัมน์)
- สไนเปอร์ขาว (H) และสไนเปอร์เลนส์น้ำเงิน (I) คลิปไม่มีค่าตัวเลขของตัวเอง ใช้ค่าของ AWM (3.7) ตามที่เอกสารระบุว่าเสียงตระกูลเดียวกัน
