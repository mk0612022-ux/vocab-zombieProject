# เครื่องมือเขียนฉากของบท (Story รอบ 5–6)

ฉากของบทเป็นข้อมูลใน `public/js/data/story/ch1.js` · ตัวรันฉาก `public/js/story/scenes.js` (หัวไฟล์มีรายการเต็ม) · รอบ 5 เพิ่มเครื่องมือที่ฉากเปิด Exam Day ใช้ และรอบ 6–10 ใช้ต่อได้ · test ที่เล่นฉากด้วยการกระทำจริง: ชุด 43 (`tools/round43-test.js`)

## ฉากหนึ่งฉาก
```js
{ id, title, objective, start: { x, y, z, yaw }, clock, light,
  hud: "none" | "all" | [...],   lens: false,      // HUD และแว่นตอนเริ่ม (รอบ 2)
  armed: false,                                      // (รอบ 5) ไม่มีปืนในมือจนกว่า ["arm", true]
  doors: { DR305: true },                            // ประตูของแผนที่ตอนเริ่ม (รอบ 4)
  cast: [...], props: [...],                         // (รอบ 5) คนและของของฉาก
  beats: [{ wait, do: [[action, arg], ...], cine }] }
```
- `cast` และ `props` วางตอนฉากเริ่ม และหายไปเมื่อขึ้นฉากถัดไป (ของที่ใช้ได้และข้อสอบซ้อมก็ล้างตอนขึ้นฉากใหม่ด้วย)
- `cine`: beat ที่ชื่อเดียวกันเป็นช่วงคัตซีน เคยดูจบแล้วกดค้างข้ามได้ (ทางเดิน คำพูด เวลา ผ่านทันที) · ห้ามมีตัวเลือก การใช้ของ ข้อสอบ หรือกดตามจังหวะอยู่ในช่วง cine

## คนของฉาก (`js/story/cast.js` `G.StoryCast`)
คนสร้างจากบล็อก (`G.VoxelChars`) ไม่ใช่ซอมบี้: ยิงไม่ได้ ไม่ทำร้ายใคร
| ใน `cast` | ความหมาย |
|---|---|
| `{ id, who, at: {x,y,z}, yaw, pose, face: "player", follow, hidden, label, carry }` | `who` = หน้าตา (`beam`, `chai`, `c1`–`c6` ผู้เข้าสอบ, `porn_z` ...) · `pose`: `stand` `sit` (เก้าอี้ 0.45 ม.) `slump` (ฟุบโต๊ะ) `floor` (นั่งพิงผนังบนพื้น) `carry` (ถือของ) `zombie` · `carry`: พร็อพในมือ (`examBox`) |

action `["npc", { id, ... }]` (สั่งหลายอย่างพร้อมกันได้):
| คีย์ | ทำอะไร |
|---|---|
| `walk: {x,z}` หรือ `[...]`, `speed`, `then` | เดินตามจุด ความสูงตามพื้น/บันได · `then`: `"hide"` `"remove"` หรือคำสั่งชุดใหม่ (เช่น `{ pose: "sit", face: -Math.PI/2 }`) เมื่อถึง · รอด้วย `{ arrived: id }` |
| `follow: true` | เดินตามผู้เล่นตามทางที่ผู้เล่นเดินจริง (ห่าง `cast.followDist`) ห่างเกิน `followLeash` หรือคนละชั้น = ย้ายมาข้างหลังผู้เล่น |
| `face: "player"` / `{x,z}` / มุม | หันไปทาง (ค่อย ๆ หัน) |
| `talk: วินาที` | หัวและมือขยับตอนพูด |
| `turn: "beam_z"` หรือ `true` | กลายเป็นซอมบี้ตัวเดิม (`true` = ตาม `turnsInto` ของหน้าตานั้น หรือ `<id>_z`) กะพริบฟ้า |
| `label: { word, flicker, depth }` / `null` | คำเหนือหัว (TOGETHER, PROTECT) วาดพร้อมโลก จึงเห็นได้ก่อนแว่นเปิดส่วนป้ายคำ · ปกติเห็นทะลุผนัง · `depth: true` (รอบ 6) ผนังบังป้าย — ใช้กับคนที่นั่งในจุดที่ผู้เล่นเดินผ่านด้านหลังผนัง (จ่าชัยในฉาก 1-1) |
| `lunge: true` | เข้าหาผู้เล่น (หยุดห่าง `lungeStop`) · `knock: เมตร` ถูกผลักถอย |
| `to: {x,y,z,yaw}` · `show` · `hide` · `remove` | ย้ายทันที / โผล่ / ซ่อน / ลบ |

รอ: `{ arrived: id }` เดินถึง · `{ near: { id, r } }` ผู้เล่นอยู่ใกล้คนนั้นภายใน r ม. (ชั้นเดียวกัน)

คนที่มองไม่เห็นไม่ถูกวาด (กฎเดียวกับของในตึกของแผนที่): คนในตึกเห็นจากในตึกเฉพาะชั้นเดียวกันหรือชั้นติดกัน (บันได) และจากนอกตึกเฉพาะตอนอยู่ใกล้ตึก (มองผ่านหน้าต่าง) · ไกลเกินหมอกไม่วาด · ไม่ต้องสั่ง `hide` เอง (`hidden` ยังใช้สำหรับคนที่ยังไม่ควรโผล่)

## ของของฉาก
`props: [{ id, kind, at, yaw, o, collider }]` หรือ `["prop", {...}]` / `["unprop", id]` · `kind` = พร็อพของ `G.VoxelProps` (`policeCar` `examBox` `papers` `lexiLens` ...) · มี collider ตามปกติ (ลงทะเบียนใน `G.ColGrid` ทันที)

## ของที่ใช้ได้ และกดตามจังหวะ (`js/story/interact.js` `G.StoryUse`)
- `["use", { id, at, size: [w,h,d], lift, prompt, sound }]` จุดที่กดใช้ได้: มองแล้วขึ้น prompt ของเกมเอง (E / ปุ่มมือบนจอ / Y คอนโทรลเลอร์) ข้อความ `prompt` (คีย์ใน strings มี `{key}`) · ใช้แล้ว flag `used:<id>` และหายไป · รอด้วย `{ used: id }` · `["unuse", id]`
- `["qte", { id, prompt, sec, window, hurt }]` กดตามจังหวะ: วงหดเข้าหาวงกลาง กดตอนตรงกัน (ปุ่มใช้งาน Space ไก A หรือแตะวง) → flag `qte:<id>` รอด้วย `{ qte: id }` · กดพลาดเสียเลือด `hurt` (ไม่ต่ำกว่า 1) แล้วเริ่มใหม่ · ค่าเริ่มต้นใน `G.CONFIG.story.use`

## ข้อสอบซ้อมแบบเล็ง (`js/story/aimquiz.js` `G.StoryQuiz`)
`["quiz", { id, items: [{ word, gloss, clue, cloze, options: [3 คำ], answer, glosses }] }]` คำตอบลอยตรงหน้า จุดของแว่นเล็ง กดไก/คลิก/ปุ่มใช้งานเพื่อตอบ · คำถามขึ้นในกล่องคำ ("Question 1 of 3") · การ์ดอธิบายถูก/ผิดใต้กล่องคำ · `word` ที่มีในคลังคำนับเข้า memory box เหมือนตอบทั่วไป คำที่ยังไม่มีในคลังเป็นแบบฝึก · `cloze` (ประโยคเว้นช่อง) แสดงเป็นอังกฤษเสมอ · สลับลำดับคำตอบเอง · จบแล้ว flag `quiz:<id>` รอด้วย `{ quiz: id }`

## หน้าจอ เสียง คำแนะนำ (`js/story/screen.js` `G.StoryScreen`)
| action | ทำอะไร |
|---|---|
| `["black", { on, sec }]` | จอดำ (โทรศัพท์ บทพูด คำแนะนำอยู่เหนือมัน) ค่อย ๆ จาง |
| `["title", { key, sub }]` | ไตเติลบทกลางจอ (อังกฤษ + ซับภาษาเมนู) |
| `["sound", "alarm" \| "bell" \| "kick" \| "static" \| "stop"]` | นาฬิกาปลุก (หยุดเมื่อหยิบโทรศัพท์) · กริ่งไฟไหม้ (ดังต่อ) · เตะประตู · เสียงซ่าวิทยุ · หยุดทุกเสียงวน |
| `["hint", key \| { key, bind } \| null]` | บรรทัดแนะนำด้านล่าง: ใช้คีย์ `.touch` / `.pad` เองถ้าผู้เล่นใช้จอสัมผัส/คอนโทรลเลอร์ · `{key}` = ปุ่มของ `bind` (`interact` `sprint` `reload` `phone`) |
| `["shake", { sec, amp }]` | กล้องสั่น |
| `["card", { id, title, rows, mark, note }]` | การ์ดให้อ่าน (ผังที่นั่งสอบ) แถว `mark` ไฮไลต์ `{name}` = ชื่อผู้เล่น · ปิดแล้ว flag `card:<id>` รอด้วย `{ card: id }` |
- ก่อนสวมแว่นไม่มีกล่องคำ: เป้าหมายขึ้นเป็นบรรทัดเล็กด้านบนแทน

## ปืน ที่นั่ง คำของฉาก
- `armed: false` ในฉาก = ไม่มีปืน (ยิง เล็ง รีโหลด สลับ ฟัน ไม่ได้ ไม่เห็นปืน ปุ่มปืนบนจอสัมผัสหาย — ปุ่มยิงกลับมาตอนข้อสอบแบบเล็ง) · `["arm", true]` ยื่นปืนให้ (ขึ้นมาแบบชักปืน)
- ปืนพกในบทสร้างจากบล็อก (`js/story/voxelgun.js`) บน rig ของปืนพกเกม จึงยิง/รีโหลดเหมือนเดิม · ปืนอื่นยังเป็นแบบแคมเปญจนกว่าจะเพิ่มกล่องให้ใน `BUILT`
- `["seat", { x, z, yaw }]` นั่งลง (ตาต่ำลง `cam.seatDrop` ขยับไม่ได้ หันได้) · `["seat", false]` ลุก
- `["spawn", { id, at, kinds, words: [{ word, gloss, who }], target }]` กลุ่มซอมบี้ที่มีคำของฉากเอง (คำฝึก: ไม่นับในคลังและยอดถูก/ผิด) `who` = หน้าตา (ลุงพร `porn`) `target` = คำที่ถาม (ความหมายขึ้นกล่องคำ)
- `["sys", { key, meaningOf: "clean" }]` ความหมายของคำฝึกในภาษาความหมายของผู้เล่นใส่ใน `{meaning}`
- `["unflag", name]` ลบ flag (เช่น `reloaded` เพื่อรอรีโหลดครั้งใหม่ `{ reloaded: true }`)
- คำที่ไม่มีในคลัง + ความหมาย 4 ภาษาอยู่ใน `js/data/story/ch1words.js` (`G.STORY_WORDS.ch1` = `practice` ของบท) — เป็นข้อมูลคำศัพท์ `tools/thai-scan.ps1` ข้ามไฟล์นี้

## ข้อควรระวัง
- จุดใช้ของเป็น mesh ซ่อน: matrix คำนวณครั้งเดียวตอนวาง (`updateMatrix` + `updateMatrixWorld`) เพราะรอบ matrix ของเฟรมข้ามของที่ซ่อน

## กฎคู่ขนานของฉาก (รอบ 6)
`beats` เดินเป็นลำดับ ส่วนสิ่งที่ผู้เล่นทำได้ตามลำดับไหนก็ได้ (ห้องข้างทาง ล็อกเกอร์ ประตูที่ลองเปิดก่อนมีชะแลง คำใบ้เมื่อผ่านไป 1 นาที) ใส่ใน `on` ของฉาก:
```js
on: [
  { id: "g2", after: "on:g1", when: { all: [{ cleared: "g1" }, { zone: "c3east" }] }, do: [["spawn", { ... }]] },
  { id: "hint60", after: "dirRead", when: { all: [{ time: 60 }, { not: { flag: "foundLib" } }] }, do: [["phone", "min6"]] },
]
```
- แต่ละกฎทำงานครั้งเดียว (flag `on:<id>` checkpoint จำไว้) · `after` = flag (หรือเงื่อนไข) ที่ต้องมีก่อน แล้ว `{ time: s }` ใน `when` นับจากตอนนั้น (เวลาจริง ไม่เร่งตามการกด Space ค้าง)
- เงื่อนไขซ้อน: `{ all: [...] }` `{ any: [...] }` `{ not: ... }` · ใหม่: `{ melee: "crowbar" }` ถืออาวุธระยะประชิดนั้น · `{ tried: id }` ลองใช้ของที่ยังใช้ไม่ได้ · `{ lock: id }` กุญแจวงล้อเปิดแล้ว
- ตัวเลือกเก็บค่าเป็น flag ด้วย: `chose:<id>:<value>` (เช่น ตอบครูมินแบบไหน → ข้อความตอบกลับคนละแบบ)
- ขึ้นฉากใหม่แล้ว flag ของฉากเดิม (`on: used: tried: card: quiz: qte: lock*:`) ถูกลบ เหลือแต่ที่ใช้ทั้งบท (`msg: ntf: read: chose:`) เพราะ checkpoint เก็บได้ 120 flag

## ของที่หาได้ ประตู กุญแจวงล้อ (รอบ 6)
| action | ทำอะไร |
|---|---|
| `["give", { melee: "crowbar" }]` | อาวุธระยะประชิดเข้าช่อง melee (ชื่อขึ้นกลางจอ) · `{ ammo: { pistol: 24 } }` กระสุนสำรองเพิ่ม |
| `["ammo", { pistol: [12, 12] }]` | กระสุนตอนเริ่มฉาก [ในแม็ก, สำรอง] |
| `["drop", { kind: "ammo", at }]` | กล่องกระสุนบนพื้น (เดินทับเก็บ 2 แม็ก) |
| `["doors", { ids: [...], blocked: { DLIBRARY: "story.hint.libBlocked" } }]` | ประตูบนแผนที่ที่ผู้เล่นเปิดเอง: จุดใช้ของที่ช่องประตู ("E: Open the door") เปิดแล้ว flag `used:door:<id>` · `blocked` = เปิดไม่ได้ (ลองแล้ว `tried:door:<id>` + คำแนะนำ) |
| `["wheel", { id, door, answer, word, clue, at, yaw, use }]` | กุญแจวงล้อตัวอักษรข้างประตู (`js/story/wheellock.js`) — ดูด้านล่าง |
| `["use", { ..., need, promptNo, deny }]` | จุดใช้ของที่ต้องมีเงื่อนไขก่อน (ประตูติด ต้องมีชะแลง): ยังไม่ครบ = prompt `promptNo` ใช้แล้วได้แค่ `tried:<id>` และคำแนะนำ `deny` |
| `["card", { plan, lines, rows, note }]` | `plan: { storey, here, route, exit }` แผนผังชั้นที่วาดจากแผนที่จริง (ห้อง เลขห้อง ทางเดิน บันได คุณอยู่ที่นี่ เส้นทางสีเขียว) · `lines: [key]` ข้อความภาษาอังกฤษในโลก (ป้าย โน้ต คำบรรยายรูป) แตะคำในคลังได้ มีซับตามระดับ |
| prop `{ id, melee: "crowbar", at, lift, rx, yaw, rz, scale }` | อาวุธวางในฉาก (โมเดลของเกม แกนยาวตามแกน y: `rx: Math.PI / 2` = นอน) · `scale` ค่าเริ่ม 1.35 · `["unprop", id]` ตอนหยิบ |
| pose `bang` | ซอมบี้ (คนของฉาก) ทุบกระจก: แต่ละตัวจังหวะของตัวเอง ได้ยินเสียงทุบเมื่ออยู่ใกล้ 12 ม. ชั้นเดียวกัน |

**กุญแจวงล้อ** (`G.StoryLock`): โลกไม่หยุด แต่เท้า การมอง และปืนเป็นของกุญแจระหว่างเปิดหน้าต่าง
- PC: A/D หรือ ←/→ (หรือขยับเมาส์ซ้ายขวา) เลือกวงล้อ · W/S ↑/↓ ล้อเมาส์ หมุน · Enter/Space ลอง · E Q Backspace Esc ถอยออกมา
- iPad: ปัดวงล้อขึ้นลง หรือแตะลูกศร · ปุ่ม Open / Step back · คอนโทรลเลอร์: D-pad ←→ เลือก ↑↓ หมุน (กดค้างหมุนต่อเนื่อง) A ลอง B ถอย
- ลองครั้งแรกนับเป็นคำตอบ Spelling ของคำในคลัง (`word`) ครั้งเดียว ทั้งถูกและผิด · ผิด: ตัวอักษรที่ผิดเป็นสีแดง การ์ดอธิบายใต้กล่องคำ flag `lockwrong:<id>:<n>` · ถูก: flag `lock:<id>` ประตูเปิด
- ซอมบี้เข้าใกล้ `lock.breakDist` หรือโดนตี หรือมีหน้าต่างเปิด: ถอยออกมาเอง ตัวอักษรที่หมุนไว้คงอยู่ · ครั้งแรกที่เปิด flag `lockopen:<id>` (กฎของฉากใช้ปล่อย Sprinter)

## ซอมบี้พึมพำคำ (รอบ 6, `js/story/whisper.js`)
ทุกฉากของบท: ตัวที่ใกล้สุดภายใน `whisper.range` กระซิบคำบนป้ายของตัวเอง (เสียงพูดของเครื่อง ต่ำ ช้า เบา ไม่ตัดเสียงอื่น) และคำบรรยาย `[whisper: "word"]` · ไม่พูดทับบทพูด ขณะเปิดกุญแจ/โทรศัพท์ · ปิดได้ด้วย `story.whisper.on: false`

## ข้อควรระวัง (รอบ 6)
- ห้องบนแผนที่มีจุดนำทาง 3 จุดต่อประตู (ใน ช่องประตู นอก) ให้ซอมบี้เดินออกจากห้องตรง ๆ ก่อนเลี้ยว: ถ้ามีแค่จุดกลางช่องประตู ซอมบี้จะเลี้ยวไปชนขอบกำแพงแล้ววนอยู่ในห้อง
- หน้าต่างกุญแจอัปเดตตัวอักษรในที่เดิม ห้ามวาด innerHTML ใหม่ระหว่างปัดนิ้ว (นิ้วที่ลากต่อจะไปที่ element เดิมที่ถูกลบ)
- คนของฉากในห้องที่ปิดอยู่ ตั้ง `hidden: true` แล้ว `show` ตอนประตูเปิด: ไม่เสีย draw call ระหว่างนั้น
